# YouTube Music для Pulsar

Интеграция Home Assistant: плеер очереди ytm-pulsar и голосовые фразы для Assist.
Скопируйте эту папку в `config/custom_components/ytm_pulsar`, перезапустите
Home Assistant и добавьте интеграцию: адрес колонки и порт `24721`.
Язык ассистента — русский. На колонке фраза начинается с «Алиса».

Ответы ассистента специально с «ютуб» кириллицей: Wyoming TTS не произносит
английское YouTube.

## После «Алиса»

| Сказать | Что делает |
| --- | --- |
| включи ютуб | очередь, которая уже была |
| запусти ютуб | то же |
| включи музыку на ютубе | то же |
| музыка на ютубе | то же |
| ютуб вперёд | следующий трек очереди |
| ютуб вперед | то же |
| вперёд на ютубе | то же |
| другой трек на ютубе | то же |
| переключи трек на ютубе | то же |
| ютуб обратно | предыдущий трек очереди |
| обратно на ютубе | то же |
| прошлый трек на ютубе | то же |
| верни трек на ютубе | то же |
| найди на ютубе … | поиск и сразу воспроизведение |
| поищи на ютубе … | то же |
| поставь на ютубе … | то же |
| включи на ютубе … | то же |
| ютуб удали все | очистить очередь |
| ютуб удали всё | то же |
| ютуб удалить все | то же |
| случайное на ютубе | очистить очередь и включить случайные треки |
| случайные песни на ютубе | то же |
| рандом на ютубе | то же |
| включи случайное на ютубе | то же |

«Включи ютуб» не запускает рекомендации, если в очереди уже есть треки:
продолжается то, что было. Подборка включается только при пустой очереди.

## Колонка берёт сама, без этого расширения

Pulsar перехватывает эти слова и до ассистента они не доходят. Во фразах
ютуба их нет.

| Сказать | Что делает колонка |
| --- | --- |
| стоп, хватит | пауза или отмена диалога |
| пауза | пауза |
| продолжи, играй | продолжить |
| дальше, следующий | следующий трек **текущего** плеера (часто Music Assistant) |
| назад | предыдущий трек **текущего** плеера |
| громче, тише | громкость колонки |

Поэтому следующий и предыдущий именно ютуба — «ютуб вперёд» и «ютуб обратно».

## Плеер в Home Assistant

Сущность `media_player` (YouTube Music):

- включить / выключить, пауза, стоп
- следующий / предыдущий
- перемотка, громкость, перемешивание
- очистить очередь
- действие **Найти на YouTube** — поиск и воспроизведение
- действие **Случайные треки** — очистить очередь и включить случайные
