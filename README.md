<h1 align="center">ytm-pulsar</h1>
<p align="center">YouTube Music на Яндекс Станции с Pulsar: веб-панель, Cast, CLI и голос в Home Assistant.</p>

Поиск, очередь, лайки и плейлисты YouTube Music. Основано на
[ytm-alice](https://github.com/SPAWNRYS-ban/ytm-alice) 0.7.6, но звук играет
медиаплеер [Pulsar](https://github.com/Morvex885/pulsar), а штатная Алиса не
нужна. Фразы перед музыкой, озвучка ошибок, подсветка и медиаслой
MPRIS/Bluetooth здесь не делаются: на Pulsar это Home Assistant и сама
колонка. Голос YouTube — интеграция
[custom_components/ytm_pulsar](custom_components/ytm_pulsar).

> [!CAUTION]
> YouTube не пускает датацентровые IP («Войдите, чтобы подтвердить, что вы не
> бот»): маршрутизируйте его через домашний или резидентный выход.

## Как это работает

Процесс сам режет поток YouTube и раздаёт его на `127.0.0.1:18883`; Pulsar
забирает его своим GStreamer по команде через ESPHome API (`127.0.0.1:6053`).
Пауза, стоп, переключение и громкость идут по одному постоянному соединению.
Позиция трека считается по состояниям медиаплеера Pulsar.

Ключ — файл `/data/pulsar/api_key` или переменная `YTM_PULSAR_API_KEY`
(base64 от 32 байт, тот же, что в Home Assistant). Если ключа нет, API
открытый. Адрес API меняет `YTM_PULSAR_API`. Если релей слушает не на самой
колонке, `YTM_PULSAR_RELAY` задаёт `хост:порт`, с которого Pulsar его скачает.
ESPHome API Pulsar принимает не больше четырёх клиентов; ytm-pulsar занимает
одно место.

Трек считается доигранным, когда Pulsar перешёл в Idle, а релей отдал
последний байт. Остановка из Home Assistant или обрыв потока помечают очередь
остановленной, а не переключают трек. Если Music Assistant (Sendspin) забрал
колонку, очередь ytm-pulsar об этом не узнает.

`ytm-alice-resolver` — статический QuickJS-хелпер, который исполняет JS плеера
YouTube и расшифровывает подписи потоков. Собирается `build-native.sh`.

## Установка на Станцию

Положите `ytm-alice` и `ytm-alice-resolver` в `/data/ytm-pulsar/bin` и
запустите:

```sh
export YAM_ROOT=/data/ytm-pulsar YTM_ALICE_DATA=/data/ytm-pulsar/var
export PATH=/data/ytm-pulsar/bin:$PATH
ytm-alice daemon start
```

Журнал — `/tmp/ytm-alice.log`.

## Веб-панель и аккаунт

Откройте **`http://IP_СТАНЦИИ:24721`**. Панель доступна в локальной сети без пароля.

В панели есть поиск, очередь и управление воспроизведением.
Для лайков и личных плейлистов войдите по коду («Войти по коду» в настройках
или `ytm-alice login tv`): access-токен обновляется автоматически. Можно также импортировать
cookies YouTube и выбрать аккаунт; инструкция по экспорту находится там же.
Поиск и воспроизведение общедоступных треков работают и без аккаунта.
Для треков с возрастными ограничениями к TV-входу нужны действующие cookies
аккаунта с подтверждённым возрастом. Подробнее: [вход и ограничения](docs/WEBUI.md#вход-по-коду-youtube-tv).

В настройках доступны радио после очереди, перемешивание, домены и порт панели.
Старый `settings.json` от ytm-alice читается; ключи голосовых команд, фразы и
подсветки в нём игнорируются. [Настройки](docs/SETTINGS.md).

## Голос в Home Assistant

Интеграция `custom_components/ytm_pulsar` добавляет плеер YouTube и фразы
для ассистента. Полный список команд — в
[custom_components/ytm_pulsar/README.md](custom_components/ytm_pulsar/README.md).
Скопируйте каталог в `config/custom_components/ytm_pulsar`, перезапустите
Home Assistant и добавьте интеграцию: адрес колонки и порт `24721`.
Язык ассистента — русский. На колонке фраза начинается с «Алиса».

Колонка сама понимает «дальше», «следующий», «назад», «стоп», «хватит»,
«пауза», «продолжи», «играй», «громче» и «тише». Их во фразах ютуба нет.

| Сказать после «Алиса» | Действие |
| --- | --- |
| включи ютуб, запусти ютуб, музыка на ютубе | очередь, которая уже была; если пусто — подборка |
| ютуб вперёд, другой трек на ютубе | следующий трек ютуба |
| ютуб обратно, прошлый трек на ютубе | предыдущий трек ютуба |
| найди на ютубе …, поставь на ютубе … | поиск и воспроизведение |
| ютуб удали все | очистить очередь |
| случайное на ютубе, рандом на ютубе | очистить очередь и включить случайные треки |

Те же действия есть у плеера `media_player` и у действий «Найти на YouTube» и
«Случайные треки». Языковой модели Assist они отданы как инструменты: она
может вызвать их и по неточной фразе.

## Трансляция с телефона

Станция видна в приложении YouTube Music как телевизор: нажмите значок
трансляции и выберите Станцию. Телефон и Станция должны быть в одной сети.
С телефона работают очередь, пауза, переключение и перемотка треков и
громкость (громкость медиаплеера Pulsar). Колонка отвечает на поиск SSDP и
принимает DIAL-запросы на порту `8008`. Отключить приём: переменная окружения
`YTM_ALICE_CAST=0`, имя в списке устройств задаёт `YTM_ALICE_CAST_NAME`.

## Установка CLI-клиента (необязательно)

На компьютере с Linux или macOS нужны Python 3 с `curses` и curl:

```sh
curl -fsSL https://github.com/SPAWNRYS-ban/ytm-alice/releases/latest/download/install-client.sh -o /tmp/ytm-alice-install-client.sh
sh /tmp/ytm-alice-install-client.sh
ytm-alice connect http://IP_СТАНЦИИ:24721
ytm-alice
```

Клиент устанавливается в `~/.local/bin`; добавьте эту папку в `PATH`, если нужно.
Команда без аргументов открывает панель: Space — пауза, `/` — поиск,
`n`/`b` — следующий/предыдущий трек, `q` — выход.

## Команды CLI на Станции

| Команда | Действие |
| --- | --- |
| `ytm-alice play "исполнитель трек"` | Включить трек |
| `ytm-alice search "запрос"` | Поиск |
| `ytm-alice select 2` | Включить второй результат поиска |
| `ytm-alice queue` | Очередь |
| `ytm-alice pause` / `ytm-alice resume` | Пауза / продолжить |
| `ytm-alice seek 60` | Перейти к минуте трека с начала ближайшего аудиофрагмента |
| `ytm-alice next` / `ytm-alice previous` | Следующий / предыдущий трек |
| `ytm-alice stop` | Остановить музыку |
| `ytm-alice status` | Текущий трек и состояние |
| `ytm-alice recommendations` | Персональные рекомендации |
| `ytm-alice shuffle-on` / `shuffle-off` | Перемешивание |
| `ytm-alice config get` | Постоянные настройки |
| `ytm-alice daemon restart` | Перезапустить сервис |
| `ytm-alice --help` | Все команды |
